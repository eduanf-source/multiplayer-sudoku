# Sudoku Together v2

Two-player real-time Sudoku with private rooms, live scores, chat, timer, difficulty levels, rematches, mobile layout and winner confetti.

## Local
npm install
npm start

Open http://localhost:3000

## Internet deployment
Upload the project files to a GitHub repository, then deploy that repository as a Node.js Web Service on Render.
Build command: npm install
Start command: npm start

The server uses process.env.PORT automatically.
